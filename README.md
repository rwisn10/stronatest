# Strona komitetu — GitHub Pages

1. Utwórz repozytorium na GitHubie i wgraj wszystkie pliki z tego folderu (index.html w głównym katalogu).
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Po minucie strona działa pod `https://TWOJ-LOGIN.github.io/NAZWA-REPO/`.

Formularze (kontakt.html): załóż darmowe konto na formspree.io i jest już ustawiony na Twój identyfikator `mkjowydg`. Wiadomości przyjdą na e-mail.
